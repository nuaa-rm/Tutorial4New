## 验证

卷一第 4 章的 USB KVM 示例改用 Sipeed NanoKVM-USB。接线图、网页操作步骤与题解依据 [Sipeed 快速上手指南](https://wiki.sipeed.com/hardware/zh/kvm/NanoKVM_USB/quick_start.html) 更新。另补入 Sipeed 官方产品图，图注说明两端接口位置。已核对导出的 KVM 正文、图和题解，硬件连接与断网操作待实机验证。

卷一第 4 章的 SSH 小节补入 X11 与 Wayland 窗口转发。在本机回环 SSH 和隔离的 X 服务器上验证了 `ssh -X` 显示 `xclock`。Waypipe 经回环 SSH 连接本机 Wayland 合成器并读到协议接口，教材中的 GTK 窗口与跨设备操作待验收。用隔离的 X 服务器检查了 `xprop` 在显示可用、未设置地址和地址无法连接时的三种结果。
