## 核心能力覆盖

| 正文 | 随堂练习标签（省略 ex:v1-build-）与判断 |
| --- | --- |
| C++ 编译过程 | stages：预测旧/新程序编号，检查宏展开、四种产物与语法失败阶段；静态/动态库由 shared-library 的实际变体复用。 |
| 项目配置 | target-name：同步修改目标相关命令，用空构建目录构建，区别项目名与产物名。 |
| 添加文件 | missing-files：缺头文件搜索目录与缺实现分别失败，恢复完整命令。 |
| 编译 | incremental-switch：改乘数与配置开关，核验重新配置/构建及输出。 |
| 链接 | shared-library：同一源码切换库类型，检查库文件和运行；章末题补目标与变量区别。 |
| 安装 | install-prefix：实际安装到另一前缀并启动，解释前缀与相对路径。 |
| 模块、作用域与排错 | module：空值与未定义值、配置函数与运行函数；public-scope：复现消费目标缺头文件。其他错误阶段由 missing-files 与 exit-code 的综合任务覆盖。 |
| OpenCV 外部依赖 | exit-code：配置/构建/显示示例完成后核验两个错误状态，再故意改包名复现配置失败并恢复；章末题核对 OpenCV_DIR 与开发包。 |

## 运行证据与边界

- 工具为 Ubuntu GCC 13.3.0、CMake 3.28.3、OpenCV 4.6.0；已有 build-essential/cmake/libopencv-dev，补装 xvfb、xdotool、x11-apps 及其依赖。测试在临时工程副本中进行，没有改用户的工作空间、系统安装前缀或教材源码。
- `scripts/verify_ch3_examples.py` 验证四阶段、宏修改/旧程序、语法失败、目标重命名、手动多文件与两种缺失、开关与增量构建、静态/共享库、两处安装、PUBLIC/PRIVATE、模块空值、OpenCV 参数/读图失败与窗口。`evidence/volume-1-chapter-3-runtime.json` 记录 54 次命令；之后新增缺包练习的两次配置另记 `volume-1-chapter-3-package-variant.json`，脚本已同步加入这两步。
- 旧程序仍输出 armor=3，重新构建后输出7；语法错误在编译阶段失败。缺包含目录报告 armor.hpp 缺失，缺实现报告 undefined reference。乘数修改后分数60，恢复后30；无文件变化的构建不重新编译，改 armor.cpp 后只重编库源文件并重新链接主程序。
- 两种库产物均生成且程序输出30；安装到 stage、stage-check 后均可运行。PRIVATE 变体中库可编译、主程序缺头文件。模块输出 Debug、未定义提示及空值 []。缺包在配置阶段失败，恢复 OpenCV 后配置成功。
- OpenCV 实际读取正文的 2×2 红绿蓝白样本，再读取同构的 320×240 四象限变体；分别输出 size=2x2、size=320x240。Xvfb 虚拟显示中实际创建窗口、截图并向窗口发送空格按下事件，waitKey 返回，程序正常退出。已查看截图 `volume-1-chapter-3-two-pixels.png`、`volume-1-chapter-3-window.png`。这是实际 HighGUI/X11 后端运行；没有将它表述成用户 Niri 桌面上的实际点击。没有参数退出1、缺图片退出2。
- ROS 选读在临时工作空间中使用 Jazzy：colcon build 成功，colcon test-result 显示3个测试无失败/跳过；heartbeat 打印 first heartbeat 和 heartbeat alive，3秒后收到 SIGINT 正常收尾，timeout 记录124。证据：`volume-1-chapter-3-ros-jazzy.txt`。这里验证构建、测试与启动，DDS、多机和 Launch 行为会在卷二按相应要求再检查。
- 核对原始文档：[CMake 链接作用域](https://cmake.org/cmake/help/latest/command/target_link_libraries.html)、[包查找](https://cmake.org/cmake/help/latest/command/find_package.html)、[安装规则](https://cmake.org/cmake/help/latest/command/install.html)、[OpenCV 读图与显示](https://docs.opencv.org/4.x/db/deb/tutorial_display_image.html)。正文使用本章实际环境支持的接口，不依赖手册中新版本才增加的功能。
