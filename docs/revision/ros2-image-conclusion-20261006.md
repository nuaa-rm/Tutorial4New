结论先回到 1440×1080 图像每 4 ms 到来、需要及时交给识别节点的问题，再由已经测得的结果给出选择：

- 同机且可合并进程，优先组件与进程内所有权交接，依据是三种 RMW 的完整交付与 0.029–0.042 ms P95。
- 跨进程沿用标准 Image，本组先选 Zenoh SHM，依据是完整交付与 P95 从 2.780 ms 降到 1.385 ms；已有 DDS 系统可采用 Cyclone DDS 共享配置，普通 Image 完整交付、P95 2.598 ms。
- 固定尺寸且接受自定义接口，选 FixedImage 与 Fast DDS Data Sharing 或 Cyclone DDS iceoryx 两端借出，依据是完整交付及 0.341 / 0.330 ms P95，再按已有 DDS 实现落实接口与池配置。
- 算法长期 8 ms 时，从队列实验得出先解决吞吐与图像年龄的方案：较小有界队列、处理最新可用帧、减负或并行、观测和存储支路分别安排。
