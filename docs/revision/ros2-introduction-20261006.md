# 卷二 ROS2 章名与章首学时调整

章名由“ROS2 基础”改为“ROS2 开发与工程实践”。本章现在包含节点与接口、完整工程、观测与回放、构建和 Launch、日志与 IDE、大图像中间件、组件与借出消息，以及性能对照，新章名对应这一范围。

章首建议学时改为：每天 2–3 小时边读边做，包含示例与练习。首次学习约 1.5–2 周，图像链路与性能对照另用 3–5 天，完整学习约 2–3 周。

估算时给入门与完整工程安排 4–5 天，观测工具 2–3 天，构建、Launch 与调试 3–4 天，进阶实验 3–5 天，合计约 12–17 天；总安排留出整理结果与复习的余量。章首只保留两阶段时间，让提要便于阅读。这是编辑预估，没有把它写成学员实测完成时间。

“大图像链路：中间件与内存”及其 13 个子节在标题末尾加 `*`，沿用教材的选读标记，新增 `sec:ros2-image-advanced` 标签。章首说明 `*` 表示进阶选读，并与该节开头共同提示首次可先跳到本章小结，遇到大图像传输、复制开销、丢帧与延迟问题时再回来。章末同步说明：先做第 1–10、15–16 题与前 5 项验收，第 11–14 题、后 3 项验收随进阶部分补做，完整学习后仍需完成全部 8 项验收，没有删除或降低完整章的任务覆盖。

学习目标把图像性能能力注明为进阶目标；Ubuntu 22.04/Humble、卷一先修和卷三实车集成边界保留。提要左栏放目标与学时、右栏放学习顺序与本卷边界，用本章局部的显式分栏避免条目从左栏末尾拆到右栏开头。同步题解标题与目录项、README 章节地图、观测示例 README、进度与审计的章名，以及本章修订记录标题。没有移动文件或改动程序、图片、题意、答案内容和正文层级。完整增量见 [changes.diff](evidence/ros2-introduction-20261006/changes.diff)。
