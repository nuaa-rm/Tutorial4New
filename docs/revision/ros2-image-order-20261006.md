# 图像链路讲解顺序调整

本轮根据读者先掌握通用路径、再学习专项优化的顺序重排卷二第一章。保留预算、中间件安装配置、完整示例、全部参考数据与原始实测证据，补写章节衔接。

## 当前阅读顺序

1. **1.3.1 图像预算**：先建立 4 ms、像素负载与队列的概念。
2. **1.3.2 中间件选择**：安装与配置 Fast DDS、Cyclone DDS、Zenoh，确认基本通信。
3. **1.3.3 组件与所有权**：用小图像比较 separate、same、intra，展示完整工程。
4. **1.3.4 借出消息**：查询类型与配置的借出能力，观察本地分配回退，再用 Zenoh 区分传输共享内存与应用借出。
5. **1.3.5 标准 Image 的 250 Hz 对照**：先读三种布局的数据，再打开 Zenoh SHM、规划池容量，最后观察慢处理与队列造成的图像年龄变化。
6. **1.3.6 Cyclone DDS 的 separate 扩展**：承接普通 Image 与 Zenoh SHM，引入 iceoryx，说明 RouDi、池容量、QoS 和直接借出时的布局条件，再定义 FixedImage、配置共享池、运行低频像素验证与高速发布对照。

“标准 Image 也能序列化后经 iceoryx 共享内存交付”与“直接借出原始样本需要固定、内嵌布局”在进入接口定义前连贯说明。定长接口由前面已经测过的 1440×1080 BGR8 负载引出。

通用借出练习与固定图像练习拆开，分别紧跟 1.3.4 与 1.3.6；参考答案按相同顺序同步。原慢处理练习仍在 1.3.5 末尾。README 与章末小结同步说明新顺序。文件没有移动、重命名，main.tex 的包含结构与共享模板保持现有组织。
