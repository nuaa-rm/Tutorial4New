# 两类图像的借出探测

借出示例改为直接比较标准 `sensor_msgs/Image` 与本章定长 `FixedImage`。两类消息都查询 `can_loan_messages()`、调用 `borrow_loaned_message()`、填充并发布相同的 1440×1080 BGR8 像素，每个字节为 42。普通 Image 使用本地分配器回退，FixedImage 在能力为 true 时直接填充中间件样本。

正文在 `A_ros2_image_path.tex` 的借出消息示例中引入完整程序并解释两种内存来源。能力表移到 `A_ros2_image_results.tex`，与统一性能结果放在一起。对应随堂练习、章末第 13 题及题解、项目 README 均已同步。没有重命名或移动文件，共享模板与五个小节的顺序保持不变。完整修改见 [probe.diff](evidence/ros2-image-loan-probe-20261006/probe.diff)。
