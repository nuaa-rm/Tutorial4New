## 官方核对依据

参考中的 `env` 单节点用法、把进程事件当作就绪、把 OpaqueFunction 称为解析阶段执行等表述，按 Humble 官方实现核对后重新讲解。官网页面本轮被访问保护拦截，改读同一官方仓库的 Humble 文档源码和对应实现：

- [替换对象教程](https://github.com/ros2/ros2_documentation/blob/humble/source/Tutorials/Intermediate/Launch/Using-Substitutions.rst)：执行时求值、资源安装、Include 与字典 items。
- [事件教程](https://github.com/ros2/ros2_documentation/blob/humble/source/Tutorials/Intermediate/Launch/Using-Event-Handlers.rst)：进程启动/退出/输出与关闭事件。
- [ExecuteProcess 实现](https://github.com/ros2/launch/blob/humble/launch/launch/actions/execute_process.py)：env 与 additional_env 的继承行为。
- [条件求值实现](https://github.com/ros2/launch/blob/humble/launch/launch/conditions/evaluate_condition_expression_impl.py)：true/1、false/0 及大小写规则。
- [GroupAction 实现](https://github.com/ros2/launch/blob/humble/launch/launch/actions/group_action.py)与 [PushRosNamespace 实现](https://github.com/ros2/launch_ros/blob/humble/launch_ros/launch_ros/actions/push_ros_namespace.py)：作用域、配置/环境恢复、命名空间弹出。
- [OpaqueFunction 实现](https://github.com/ros2/launch/blob/humble/launch/launch/actions/opaque_function.py)：动作执行时调用回调，传入 context 并返回实体。
- [生命周期说明](https://github.com/ros2/ros2_documentation/blob/humble/source/Tutorials/Demos/Managed-Nodes.rst)：配置、激活和状态管理的适用范围。
