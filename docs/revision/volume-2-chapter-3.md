## 项目与覆盖

项目为本卷 `examples/sdr/iq-replay-demo`，包含八个 Python 文件和 README。正文展示目录与全部 231 行核心源码，按执行顺序说明 frame→synth→record→decode→字段，以及独立的 tone、state、capture 入口。拆分只沿职责/函数边界，行号连续，没有“见源码自行阅读”代替讲解。

离线接收为矩形 BPSK、已知频偏/符号率、整数样本偏移、恒定相位、轻噪声与固定单帧；没有把它称作赛场接收机。载波补偿、前导相关、相位恢复、符号均值、硬判决、帧 CRC 和米值转换形成完整流程。符号平均演示的是该矩形波形的积分/匹配处理，不声称包含通用滤波、频偏估计或连续流恢复。

| 核心内容 | exercise 标签（省略 ex:v2-sdr-）与判断 |

## 运行与环境

证据为 [volume-2-chapter-3-runtime.json](evidence/volume-2-chapter-3-runtime.json)，脚本 `scripts/verify_sdr_examples.py`。实际环境 Distrobox ubuntu2404 / Ubuntu 24.04.5、Python 3.12、NumPy 1.26.4；本章没有 ROS 接口，不把 Jazzy 导入环境写成射频测试。

- tone 和 16000 Hz 变体核对复数旋转、主值与混叠。两次独立进程生成/读取 670 样本，起点 19，帧 010704e209c40584，序号 7、坐标 (1.25,2.5) 米。
- π 相位、2000 mm、负相位/负频偏/3000 mm 组合分别保存回放；另外 5 种前置长度×5 种相位×3 种已知频偏，共 75 组轻噪声变体检查起点和字段。
- CRC 损坏实际退出 1；另核验录包不足、弱前导、频偏元数据错误、非法 sps、帧长度/未知命令、数量/dtype/采样率元数据、IQ 字节篡改和 NaN 拒收。错误命令重新计算 CRC，证明命令检查独立于 CRC。
- 跳过相位补偿时前导比特全部翻转，完整流程仍恢复坐标；状态练习序列和初始 reset 代次、未来/过期/年龄恰好等于阈值/两源优先级通过。
- 容器按授权安装 libiio0/libiio-utils 0.25 与 libad9361-0 0.3；pyadi-iio 0.0.21、pylibiio 0.25 装在独立临时虚拟环境（避免系统 pip），import 实际成功，capture --help 参数核验。正文让读者在项目 .venv 用同样组合，文件名/目录是可替换项。
- 首次全后端扫描因 Avahi 未运行报错，检查安装版本帮助后用 iio_info -S usb，实际输出 No IIO context found。没有为扫描修改宿主机服务、没有开启发射或连接未知设备。模拟对象只核验属性设置、保存和读取失败仍清理的代码路径，不当作真实设备结果。

接口核对采用 [NumPy 卷积](https://numpy.org/doc/stable/reference/generated/numpy.convolve.html)、[NumPy 数组读取](https://numpy.org/doc/stable/reference/generated/numpy.load.html)、[ADI 虚拟环境与 libiio 边界](https://analogdevicesinc.github.io/pyadi-iio/guides/quick.html)、[ADI AD936x/Pluto 接口源码](https://github.com/analogdevicesinc/pyadi-iio/blob/main/adi/ad936x.py)。不使用非官方赛季波形推断真实规则。
