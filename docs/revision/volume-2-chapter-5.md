完整工程为本卷 `examples/dl/lenet-training-demo`：14 个 Python 文件共 327 行，另有固定导出依赖、README 和输出忽略规则。正文在相关知识点展示全部核心源码；train、infer、export_compare 按逻辑边界连续分段，行号连续，没有删掉函数中段。data/model/engine/train/infer 构成实际训练主线，其他脚本把拟合、算子、损失、梯度、状态、设备、NMS 与计时各自缩小成可检查实验。

12 道随堂练习覆盖拟合、解释器、集合划分、算子、尺寸、梯度、模式、完整训练、加载、CUDA、NMS 和导出/计时。损失与优化合用 grad 练习：任务要求手算更新、区别梯度累加与 step；部署节合用 deploy 练习：任务同时要求真实样本跨运行时误差和批量计时。10 道章末题包含基础、数据泄漏/部署边界提高和独立推理实践。22 个答案都用 ref 定位，给输出或开放任务的判断依据。

## 实际运行与范围

证据为 [volume-2-chapter-5-runtime.json](evidence/volume-2-chapter-5-runtime.json)，完整训练指标另存 [volume-2-chapter-5-metrics.json](evidence/volume-2-chapter-5-metrics.json)。脚本 `scripts/verify_dl_examples.py` 记录源文件和权重散列；完整训练与 GPU 小规模训练先按正文入口实际运行，再以明确标记复用同一源码的日志，其他变体独立运行。没有反复训练以挑选更好成绩。

环境为 Distrobox ubuntu2404 / Ubuntu 24.04.5 / Python 3.12.3 / NumPy 1.26.4，CPU 环境使用 PyTorch 2.6.0+cpu / torchvision 0.21.0+cpu，GPU 环境另建 2.6.0+cu126 / 0.21.0+cu126。导出依赖为 onnx 1.17.0、onnxruntime 1.20.1。实际 GPU 为 RTX 3070 Ti Laptop、宿主驱动 615.71.09；没有改宿主驱动。

- MNIST 来源 60000 张固定拆为 55000 训练 / 5000 验证，另有 10000 测试；集合索引互不重叠。批量 50 的 128 张变体实际为 50/50/28。独立验证不等批量损失按样本加权，与全样本 criterion 均值一致。
- CPU 三轮训练的验证损失为 0.091698/0.073152/0.060322，按最小验证损失选择第三轮；最终只评一次测试，准确率 0.9853。曲线直接读取这份真实记录，不根据预计趋势绘制。成绩不保证其他配置复现，也不能推断装甲板识别效果。
- 拟合无扰动、步幅 2、全 1 核、学习率 0.05、Dropout 0、NMS 0.8、32 输入报错/修正均实际验证。Dropout 后 clone 避免 p=0 原样返回输入时误读 requires_grad，正文也解释这一点。
- 独立推理 0/1/2/9999、非法 10000、结构标识错误、Linear 尺寸错配、CPU 请求 CUDA、非法训练参数均验证；正常参数重新加载与原输出完全一致。CUDA 训练产出的 CPU 张量也在 CPU 进程读取。
- 真实 CUDA 128 张一轮训练可执行；主线 CPU 参数与相同输入在 CUDA 上最大差为 2.3841858e-7，满足相对 1e-4 / 绝对 1e-5 容差。不以可用性比较充当速度实验。
- ONNX 对实际测试索引 0/1/2 比较全部十个分数，最大绝对差分别约 9.54e-7、2.86e-6、1.91e-6；预测为 7/2/1。固定 batch=1 和 28×28 限制对 batch=8 与 32×32 输入实际拒收。
- CPU 单线程预热后计时，批量 1/32/8 均实际运行。批量 1 中位数约 0.1055 ms，32 约 0.6422 ms；这是本次纯前向结果，不包含采集、预处理、排队、传输或后处理，不承诺 GPU 或赛场加速。

依赖组合核对使用 [PyTorch 固定版本安装表](https://docs.pytorch.org/get-started/previous-versions/)；算子、导出与 NMS 使用 [Conv2d 2.6 文档](https://docs.pytorch.org/docs/2.6/generated/torch.nn.Conv2d.html)、[ONNX 导出 2.6 文档](https://docs.pytorch.org/docs/2.6/onnx.html) 和 [torchvision 0.21 NMS 文档](https://docs.pytorch.org/vision/0.21/generated/torchvision.ops.nms.html)。历史检测结构依据 [YOLOv5 v1.0 官方配置](https://github.com/ultralytics/yolov5/blob/v1.0/models/yolov5s.yaml)，不是所有 YOLO 版本的通用结构。ONNX Runtime 运行方式核对 [官方 Python API](https://onnxruntime.ai/docs/api/python/api_summary.html)。
