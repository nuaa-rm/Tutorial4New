修订日期：2026-10-31。新增在第四章之后、“卷一小结”之前，承接“自己的电脑能运行”到机器人实机部署的过程。没有移动或重命名既有章节，旧版本由 Git 历史保留。

## 内容与入口

`01-基础通识/Chapter5/chapter.tex` 负责章首提要、子文件入口、本章小结、10 道章末习题与 5 项现场验收。正文分工如下：

| 文件 | 教学任务 |
| --- | --- |
| `physical.tex` | 自己电脑能跑的局限、机载电脑与部署、便携屏/键鼠接线，以及蹲地调试的不便。 |
| `ssh.tex` | OpenSSH 双端职责、首次指纹核验、密钥与别名、错误分层、VS Code Remote -- SSH。 |
| `desktop.tex` | Ubuntu 22.04 GNOME RDP、Remmina/mstsc、RustDesk；登录会话、Wayland/X11、无头和重启边界。 |
| `network.tex` | DHCP、地址/路由、DNS 与 `.local`、Avahi/NSS、NetworkManager 双端有线静态地址与恢复、Tailscale 安装/登录/MagicDNS/授权及密钥到期。 |
| `deployment.tex` | 目标架构与依赖、scp/rsync、独立候选目录、版本/模型/参数记录、回退和板端验收证据。 |
| `operations.tex` | tmux、完整心跳源码与 systemd user unit、失败恢复、htop、磁盘与 journal 日志。 |
| `kvm.tex` | 有线 SSH 到硬件 KVM 的选择；Openterface Mini-KVM、PiKVM、单线的真实边界、带外救援与赛事要求。 |

全章有 18 个完整示例、13 道随堂练习、10 道章末题，答案全部追加在原有 `answers.tex`，按引用定位。远程桌面两个工具共用一项完整实验；USB/IP KVM 共用一项场景选择与接线任务，覆盖各自的验证条件，不机械增加同义题目。
