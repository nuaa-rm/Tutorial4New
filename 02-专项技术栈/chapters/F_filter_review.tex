\section{本章小结}
先区分过程变化与观测误差，再选择状态变量、单位和模型。低通用平滑换取一定延迟；Kalman 用模型预测和新观测更新状态与协方差。应熟练核对 Q、R、P、K 的含义和尺寸，验证简单数值步骤；EKF 和 UKF 的推导可按项目需要深入，但不能跳过残差和模型适用性检查。

\begin{problemset}
\item 基础：未建模加速度与传感器随机读数误差分别属于哪类不确定性？
\item 基础：一阶低通初值 0、输入恒为 2、系数 0.25，前两步输出是多少？
\item 基础：先验方差 2、观测方差 3、H=1，增益是多少？先验值 4、观测值 9，更新值是多少？
\item 基础：两个独立无偏估计的方差均为 4，平均后的方差是多少？若完全相关还能这样计算吗？
\item 基础：EKF 与 UKF 分别用什么方式处理非线性传播？
\item 提高：位置状态用 m，观测却直接填 mm，会发生什么？仅调大 R 能修复吗？
\item 实践：运行本章一维更新程序，保持其它条件不变，把 R 从 0.9 改为 9。记录 K、x、P。
\end{problemset}

\section{本章验收}
\begin{enumerate}
    \item 对同一含噪序列运行低通与滑动平均，展示原始和滤波曲线，指出阶跃后的跟踪延迟。
    \item 用位置与速度组成一维常速度模型，向检查者解释状态转移、观测矩阵及 Q、R，现场执行一步预测和更新。
    \item 选做：运行含真值的 Kalman 序列实验，同时比较跟踪误差与延迟，不能只报告输出方差变小。
\end{enumerate}
