\section{本章小结}
到这里，图像已经从一块像素数组走到可以筛选的几何形状了。首先检查输入和 Mat 的类型、尺寸与共享关系，再选择颜色或灰度分割；滤波与形态学处理让噪点和孔洞可控，轮廓描述形状，变换与绘图要跟着输出坐标走。每一步都能保存和核对，最后一个框画错时就不用从头盲猜。ORB 是另一类纹理描述工具；ROS 图像接口还要保证实际像素、编码与 Header 一致。先练熟完整流水线和中间图检查，具体检测阈值、匹配几何与赛场算法继续查对应章节和官方接口。

\begin{problemset}
\renewcommand{\theenumi}{\arabic{enumi}}
\item\label{prob:v2-cv-1} 基础：CMake 找到 OpenCV 后，头文件或链接仍失败，应检查什么？怎样确认实际用到哪一版？
\item\label{prob:v2-cv-2} 基础：10×20 的 CV\_8UC3 图像，不考虑填充时占多少字节？ROI 为什么可能不是连续数组，clone 又改变什么？
\item\label{prob:v2-cv-3} 基础：imread 返回空 Mat 时能否继续 cvtColor？视频文件结束与摄像头异常为什么不能都简单认定为“成功读完”？
\item\label{prob:v2-cv-4} 基础：8 位 HSV 的 H=178 与 H=2 是否可能都是红色？普通二值阈值恰好相等时输出什么？自适应阈值的 C 起什么作用？
\item\label{prob:v2-cv-5} 基础：孤立椒盐点先试哪种滤波？开、闭运算先后怎样，核太大有什么代价？
\item\label{prob:v2-cv-6} 基础：20×10 实心矩形的 contourArea 为什么常为 171 而非 200？从掩膜和 Canny 边缘提轮廓是否在量同一对象？
\item\label{prob:v2-cv-7} 基础：100×60 各边缩为 0.5，尺寸和原来 (40,20) 点的新坐标是多少？二值类别图和显示图为什么可能用不同插值？
\item\label{prob:v2-cv-8} 提高：本例 ORB 描述子用什么距离？如何进一步检查匹配符合平移关系，为什么只有低距离不够？
\item\label{prob:v2-cv-9} 提高：三通道能否证明是 BGR？将三通道数据只改 encoding 为 mono8 会怎样？输出 Header 为什么不应在处理完成时改成 now？
\item\label{prob:v2-cv-10} 实践：在流水线中只保留低 H 段，预测合成画面的哪些目标消失；运行并记录各阶段像素数、外轮廓、保留数量与图片。说明这是哪个阶段的条件变化，不要用降低面积阈值掩盖颜色漏检。
\end{problemset}

\section{本章验收}
\begin{enumerate}
\item 从随书工程构建、读取检查者给出的图片，展示正确窗口、保存及错误输入提示；无相机时用生成视频演示逐帧读取和退出，相机参数另做实机核对。
\item 对检查者调整过的小场景保存颜色掩膜、开闭、边缘和绘图结果，从中间图定位目标在哪一步消失，解释像素计数与轮廓面积的差别。
\item 现场更改 ROI 并展示共享修改与独立 clone，随后在缩放后图像的正确位置绘图，指出类型与坐标边界。
\item 运行 Jazzy 图像桥接回调，展示输入输出编码、像素、时间与 frame\_id；向输入注入坏编码，检查错误日志并验证随后正常帧仍能处理。硬件相机与其他发行版未验收时如实记录。
\end{enumerate}
