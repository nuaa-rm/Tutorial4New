# 卷二《专项技术栈》改造记录

处理范围：`02-专项技术栈` 的 11 章及 ROS2 完整工程附录。后续已整合 ROS 疑难杂症资料，逐文件对应与版本修正见 `ROS资料整合说明.md`。

## 教学结构

- 11 章的章首提要均为学习目标、建议学时、本卷边界三项。
- 正文按原有主题顺序保留；`main.tex` 控制章和节，正文从 `subsubsection` 开始，细分标题不再产生多余的零级编号。未修改公共导言、模板类或层级映射代码。
- 共 94 个 `example`、82 个 `exercise`、20 个 `conclusion`。原有调用片段作为接口讲解保留，完整示例明确了输入、运行步骤或演算过程及预期结果。
- 11 章均按“本章小结 → problemset → 本章验收”收尾；章末题共 88 道，每章 6–10 道，覆盖基础、提高和实践。
- 参考答案参照卷一集中在卷末 `answers.tex`：按章分别编排 82 道随堂练习与 88 道章末题，共 170 份题解。每份题解使用 `solution`，可通过 ElegantBook 的 `result=noanswer` 选项隐藏。正文只保留题目；验收保留原考核主题，改为可演示的任务及提交证据。
- 章末内容分别存放在 `chapters/*_review.tex`，便于后续单独维护。

## 主要修正

- ROS2：纠正 ROS 与操作系统的关系、包/节点/组件/执行器的职责、QoS 深度和发布频率的区别；补加载环境步骤，统一自定义消息命名、依赖、可执行目标及文件路径。重整原附录中重复且不完整的 CMake 与 XML 配置。
- 通信与 SDR：将 Markdown 表格改为三线表；提供本机环回、半包/粘包、CRC 拒收重同步、连接代次、合成 IQ、状态切换和数据时效示例。明确教学协议与实际裁判协议的区别。
- OpenCV：补完整构建入口、合成图像操作、文件/摄像头读写、颜色/阈值/滤波/形态学/轮廓、变换、ORB 及图像消息转换示例。
- 深度学习：修正 torch 安装包名、LeNet 输入通道、展平尺寸、激活接口、训练函数语法和变量拼写；增加训练/验证/测试划分、可直接保存运行的完整训练程序、参数保存加载及推理计时。
- CUDA：增加边界长度和全部结果校验、API 错误检查、驱动安装警示及常用参数说明；不再把旧 cuDNN 压缩包目录作为通用安装方法。
- 相机：修正光圈定义、电子快门读出、增益与光子数、Bayer/RGB 数据量等解释；补曝光、噪声、格式、Gamma、景深、同步和标定的操作或演算。
- 滤波/几何/MPC/导航：补数值演算、阶段小结及练习；纠正矩阵 Kalman 增益、QR/RQ 分解顺序、纯延时与失真、Dijkstra 与普通广度优先搜索的区别等关键问题。
- 排版：补图标签、规范图宽和位置，修复目录树缺字与过长链接/命令越界。链接换行设置只作用于卷二入口。
