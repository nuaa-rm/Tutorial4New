# 相机标定与 ROS2 标定包补充

新增完整正文 `chapters/E_calibration.tex`，在相机章已有离线标定示例之后载入；ROS2 章增加交叉引用。保留原有章节与练习主题，未修改模板。

## 内容

- 针孔内参、五参数畸变、光学坐标系、裁剪缩放对内参的影响，以及板到相机位姿与机器人安装外参的区别。
- 标定板规格、平整度、打印比例、固定成像模式、多位置多倾角采集、重投影误差和独立验证。
- 提供完整的验证照片程序，计算残差并保存去畸变图与新内参；独立脚本在 `examples/camera_calibration/check_holdout.py`。
- Ubuntu 22.04 / Humble 的 camera_calibration 安装、话题与服务检查、单目和双目命令、SAVE/COMMIT、YAML 手动加载、CameraInfo 与 image_proc 校正。
- 解释 approximate 只负责图像配对，不解决曝光同步；区分原图参数和校正后参数，避免重复去畸变。
- 新增 3 道随堂题与 2 道章末题，答案集中在卷末；原相机章最后一道 HDR 练习顺延至 7.13，相机章章末共 10 题。增加驱动重启后的部署验收。

## 官方依据

已读取 [image_pipeline Humble 分支](https://github.com/ros-perception/image_pipeline/tree/humble/camera_calibration) 中的 CLI、calibrator、camera_calibrator 与 image_proc 启动文件，核对参数解析、图像和服务名、归档路径、YAML 名称、时间同步选项及命名空间参数。

模型与接口参考 [OpenCV calib3d](https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html)、[Humble CameraInfo](https://docs.ros.org/en/humble/p/sensor_msgs/msg/CameraInfo.html)。命令未混用 ROS1 的 rosrun、roscore 等接口。

## 验证范围

两个新 Python 示例通过语法检查，内参裁剪缩放示例已执行断言；独立脚本与教材代码一致。检查了 TeX 环境配对和相机章随堂 7.1--7.13、章末 1--10 的答案编号。

当前主机未安装 OpenCV 或 ROS2，且未连接相机；真实照片标定、GUI、驱动写入、重启恢复和双目同步仍需按教材在目标环境验收。设备驱动启动命令和 camera_info_url 支持情况取决于实际型号，正文明确了输入接口和查验步骤，没有虚构通用厂商命令。
