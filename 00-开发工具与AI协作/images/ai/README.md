# AI 开发章的真实截图与脱敏

三张图片均以 2026-10-31 本机 Linux 上运行的 ChatGPT 桌面版 Codex 入口的真实窗口截图为基础，通过 Niri 的窗口截图命令获取。主界面与差异面板的隐私区域使用骨架占位处理，真实软件控件和代码保留原像素。桌面应用的精确构建号未单独确认，以截图日期与实际界面为准。

| 文件 | 教学用途 | 隐私处理 |
| --- | --- | --- |
| `desktop-overview_revised.png` | 侧栏、对话、输入与改动入口的区域导览 | 项目/聊天名、标题和正文改为圆角骨架条、消息占位；头像为中性圆形；保留 1–4 数字标注 |
| `composer-controls_revised.png` | 输入区、权限、模型/模式与停止控件 | 只取输入区和改动入口，没有侧栏、对话或账号信息 |
| `review-pane_revised.png` | 未暂存范围、文件头、行号与新增内容 | 文件路径改为低对比度圆角骨架条；真实代码、行号和计数不变 |

原始截图未放进仓库。本次以 Git 中已经脱敏的图片为输入，使用内置 imagegen 编辑候选，再通过坐标蒙版仅合入原隐私区。生成候选在合成时对齐原尺寸；未直接采用整张生图，避免重绘控件和代码。原隐私区以外的像素逐一比较不变，四个教学标号、输入区、差异代码与工具栏另行核验。没有添加虚构的命令、运行结果或无意义文字。

占位用于保护隐私，不表示真实加载状态；图注和相邻正文已说明。入库 PNG 去除元数据、关闭透明通道并展平，不包含隐藏图层。旧实心遮挡版保留在 Git 提交 `bc7b581`，不在源码目录添加备份。

生成脚本：[prepare_ai_screenshots.sh](../../../scripts/prepare_ai_screenshots.sh)。调用形式：

```bash
bash scripts/prepare_ai_screenshots.sh \
  已脱敏主图.png 已脱敏差异图.png \
  主图生图候选.png 差异生图候选.png 尚不存在的输出目录
```

脚本只接受已经脱敏、已经裁剪的 2560×1495 主图与 1070×860 差异图，不能用于原始含隐私的截图。相同尺寸也不代表其他布局可直接套用，仍须逐张核对。脚本输出两张候选；输入区局部图没有隐私遮挡，本次不变。最终沿用 `_revised` 文件名，不重复追加标记。

生图提示词、生成与局部合成方式、像素及 PDF 检查记录见 [本次证据](../../../docs/revision/evidence/ai-development-skeleton-20261031/)。
