# AI 开发章的真实截图与脱敏

三张图片均来自 2026-10-31 本机 Linux 上运行的 ChatGPT 桌面版 Codex 入口，通过 Niri 的窗口截图命令获取。没有采用官方 HTML/CSS 重绘示意图，也没有生成或重绘软件控件。桌面应用的精确构建号未单独确认，以截图日期与实际界面为准。

| 文件 | 教学用途 | 隐私处理 |
| --- | --- | --- |
| `desktop-overview_revised.png` | 侧栏、对话、输入与改动入口的区域导览 | 项目及聊天名、标题、对话正文、账号头像以实心块覆盖；添加 1–4 数字标注 |
| `composer-controls_revised.png` | 输入区、权限、模型/模式与停止控件 | 只取输入区和改动入口，没有侧栏、对话或账号信息 |
| `review-pane_revised.png` | 未暂存范围、文件头、行号与新增内容 | 只取差异区域，遮挡相对文件路径；代码是本教材新增正文 |

原始截图仅在 `/tmp` 中处理，没有放进仓库。入库 PNG 已去除元数据、关闭透明通道并展平，不包含隐藏的原图图层。遮挡仅处理身份及项目内容，功能按钮、状态和代码画面不作改写。图注明确说明脱敏、局部取景和教材数字标注。

生成脚本：[prepare_ai_screenshots.sh](../../../scripts/prepare_ai_screenshots.sh)。调用形式：

```bash
bash scripts/prepare_ai_screenshots.sh 主界面原图.png 差异面板原图.png 尚不存在的输出目录
```

脚本限定本次核对过的 2560×1550 原图尺寸，防止套用坐标时错位；相同尺寸也不代表其他截图可以直接套用，必须重新逐张检查内容和遮挡范围。候选图先人工检查，再放入本目录并使用 `_revised` 标记。原始窗口大小、主题与字形保持实际状态，教材以截图和步骤互相补充。
