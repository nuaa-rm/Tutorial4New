本部分以windows11系统为例进行安装说明，如有使用特殊体质mac系统还请寻找其他方法（也许后续会补充进来）。
安装双系统主要分为以下四个流程：系统分区，制作启动盘，从U盘进行安装，系统设置相关。下面将进行一一说明。
\subsubsection{系统分区}

\begin{note}
制作双系统的第一步是需要获得一个空闲的系统盘分区，这一步我们一般需要在Windows系统下完成，但是如果你本来就有一个空闲的分区，比如说我的D盘里面没有什么数据，我想直接把整个D盘都作为下面的Ubuntu系统盘，你也可以跳过这一步，直接在Ubuntu安装时选择整个D盘作为对应分区即可（不过Ubuntu里面看不到具体的"D盘"字样，你得按照容量选择）。
\end{note}


右键桌面上的"此电脑"图标，点击"管理"选项，进入"磁盘管理"界面，在这里你一般会看到电脑上存在若干个磁盘分区如下图所示。

\begin{note}
你也可以换用一些比较高级的分区工具，例如DiskGenius来完成这一步。
\end{note}

\begin{note}
分区操作直接作用于磁盘，动手前请确认重要文件已有备份。"压缩卷"只是划出一块空闲区域，不会删除数据，但后续安装环节的格式化操作会。
\end{note}

\subsubsection{制作启动盘}
首先需要一个内存大于16GB的U盘，请先对其中的文件进行备份，后续操作需要格式化这个U盘。

然后进入ubuntu官网下载ubuntu22.04版本的镜像，下载链接为

\url{https://ubuntu.com/download/alternative-downloads}

注意是下载22.04.5 Desktop！

下载好后还需要下载一个启动盘制作器来将刚刚的ISO写入U盘中，这里介绍UI最简单的balenaEtcher，你也可以自行下载其他烧录器，比如软碟通（UltraISO）或是Rufus，balenaEtcher的下载链接

\url{https://etcher.balena.io/} 

安装后点击"Select image"选择刚刚下载的ubuntu镜像，随后在"Select target"中选择你的启动盘，最后点击"Flash!"即可。

在下一步"安装类型"中一定一定要选择"其它选项"！！！

然后来到"安装类型"，在这里我们需要创建ubuntu的分区（注意内存大小依然是以MB为单位）并挂载到相应的挂载点上。这里有两种方法：
\begin{enumerate}
	\item \textbf{全部挂载到根目录下}

找到之前压缩出来的空闲区域，双击选项，在弹出窗口的挂载点一栏输入"/"即可。这种方式最简洁明了，适合啥也不明白的新手操作，相当于一个只有C盘的Windows系统，所以在备份系统镜像的时候无法按照不同分区分开备份，重装系统会导致所有数据丢失，因此建议还是按照第二种方法进行分区。

\item \textbf{挂载到不同目录下}

先分逻辑分区，再分主分区。
	\begin{enumerate}
		\item "/boot"启动分区:逻辑分区，一般选择200M-2G，放置Ubuntu的启动引导文件。
		\item "/swap"交换分区（虚拟内存）:逻辑分区，一般分16GB就够了，也可以设置为物理内存大小，或是其倍数关系。如果你觉得你的物理内存够大（32G，64G等），也可以不设置。
		\item "/" 根分区（root分区）:逻辑分区，80GB左右差不多。
		\item "/home"分区:主分区，剩下的容量一起分给/home就好，平时文件也都放这边，要的空间最大，不过也可以不设置，和根分区合并。
	\end{enumerate}

点击压缩的空闲区域，点击左下角的加号：

\begin{figure}[H]
    \centering
    \includegraphics[width=0.7\textwidth]{install4.jpg}

    \label{fig:install4} % 图片标签，用于引用
\end{figure}

在弹出的窗口选择大小，新分区类型，新分区位置，文件系统类型，挂载点，依次对"/boot"，"/swap"，"/"，"/home"进行分区

\begin{figure}[H]
    \centering
    \includegraphics[width=0.7\textwidth]{install5.jpg}
    \caption{分区} % 图片标题
    \label{fig:install5} % 图片标签，用于引用

    \label{fig:install6} % 图片标签，用于引用
\end{figure}

\end{enumerate}

\begin{conclusion}
两种分区方案对比：

\begin{center}
\begin{tabular}{ccc}
\toprule[1.5pt]
方案 & 优点 & 缺点\\
\midrule[1pt]
全部挂载到 / & 操作简单，不易出错 & 重装系统会清空所有数据\\
/boot、/swap、/、/home 分开 & 重装时可保留 /home 中的数据 & 步骤较多，需提前规划容量\\
\bottomrule[1.5pt]
\end{tabular}
\end{center}

建议按第二种方案分区：日后重装系统时能保留 /home 下的工作数据——不然就只能抱着移动硬盘含泪抢救数据了。
\end{conclusion}
分区完成后点击"现在安装"，选择时区"Asia/Shanghai"就行了。然后填写用户名和计算机密码，如果在上一步中填过了就不需要再填了。

点击"继续"，系统就会对ubuntu系统开始安装了，出现安装完成的提示后点击现在重启"，等待一会，出现提示"Please remove the installation medium,then press ENTER"后拔掉启动盘并按下ENTER键，进入ubuntu系统的启动引导。在启动页面选择Ubuntu，电脑正常启动后就会进入Ubuntu系统，至此安装就全部完成啦。

ubuntu系统初始是一个什么都没有的状态，但是大家配好了也是可以和windows一样的，接下来各位就按照自己的习惯和喜好进行配置吧。

\begin{note}
安装完毕后，可能会出现电脑直接黑屏的情况，这也不用担心。这多半是由于缺少显卡驱动导致的。如果你的电脑中有独立显卡，那在使用ubuntu之前请在BIOS中将显卡选择为"混合模式"而非"独显直连"，你需要先通过"混合模式"进入系统，然后安装完毕显卡驱动后，再切回"独显直连"。
\end{note}

\subsubsection{系统设置相关}
ubuntu系统安装完成后你的默认启动系统会变成ubuntu，而有的电脑无法通过ubuntu的启动引导进入windows系统，这里我们有一种简单的办法，默认启动Windows选项，只在你需要ubuntu时主动去选择启动ubuntu。

\begin{note}
如果你觉得每次都需要手动调整这些比较繁琐，我们也有稍微复杂一些的方法。但是配置完毕后可以轻松切换系统，而且再也不会有丑丑的黑框框，详见下面的grub美化章节。
\end{note}

首先重启电脑，重启时快速重复按下启动选项快捷键，进入启动引导，在这里选择windows系统即可启动windows。如果常用的系统还是windows，想优先启动windows系统，可以进入BIOS修改启动顺序。进入BIOS依然需要重启电脑，重启时快速重复按下进入BIOS的快捷键，各个主板的快捷键有所不同，可以参考下表进行操作。

\begin{figure}[H]
    \centering
    \includegraphics[width=0.7\textwidth]{install7.png}
    \caption{BIOS快捷键一览} % 图片标题
    \label{fig:install7} % 图片标签，用于引用
\end{figure}

进入BIOS后找到Boot相关设置，根据电脑提示将Windows Boot Manager移到ubuntu的启动引导上方，保存退出即可。

\begin{exercise}
重启电脑进入 BIOS，找到 Boot 启动顺序设置并记录当前的启动顺序（不需要修改），确认自己知道如何将 Windows Boot Manager 调整到首位。
\end{exercise}

\subsubsection{系统扩容*}

如果系统中的文件已经多到空间不足了，那么此时我们就需要给ubuntu系统进行扩容。

扩容可以使用ubuntu自带的gparted分区管理工具，也可以类似第一步中使用Windows下的分区工具进行。不过上面既然介绍过了Windows下的工具，这里我们就换换口味，使用ubuntu下的gparted分区管理工具吧。

安装并启动 gparted 分区工具：
\begin{tbash}
sudo apt-get install gparted
sudo gparted
\end{tbash}

进入gparted图形化界面，可以看到这里显示了电脑中的ubuntu和windows的所有分区，选中你要扩容的ubuntu分区，可以看到上方有一个箭头形状的图标亮起

\begin{figure}[H]
    \centering
    \includegraphics[width=0.7\textwidth]{linux10.png}
    \caption{gparted图形化界面} % 图片标题
    \label{fig:linux10} % 图片标签，用于引用
\end{figure}

但是我们如果直接点击箭头图标却会发现以下报错：

\begin{figure}[H]
    \centering
    \includegraphics[width=0.7\textwidth]{linux9.png}
    \caption{gparted扩容失败} % 图片标题
    \label{fig:linux9} % 图片标签，用于引用
\end{figure}

这是因为当你处于ubuntu系统时，自己系统的分区是被使用而被上锁的，所以此时你无法对分区进行修改。但是其实解决方法也很简单，我们可以在启动盘中的ubuntu系统中对自己的ubuntu分区进行修改。

在切换之前还有一件事要做：调节linux-swap和extend分区位置（如果存在的话），这是因为使用gparted扩容时只能对相邻的分区进行操作，如果swap和extend分区挡在ubuntu分区和windows分区之间，那么就不能从这个windows分区中分出空间给ubuntu分区了。

调节完毕之后插上安装ubuntu系统时制作的启动盘，重启电脑，重启时快速重复按下启动选项快捷键。进入启动选项界面后通过上下键选择Linpus lite选项，回车，进入系统安装程序，选择Try or Install Ubuntu，再回车，这些步骤和安装ubuntu时是一样的，只是进入安装页面后，这次我们要选择试用Ubuntu

\begin{figure}[H]
    \centering
    \includegraphics[width=0.7\textwidth]{install2.jpg}
    \caption{进入试用ubuntu界面} % 图片标题
\end{figure}

选择试用后我们会进入到ubuntu的主页面，打开终端，再次打开gparted

\begin{tbash}
sudo apt-get install gparted
sudo gparted
\end{tbash}

此时就可以对原来ubuntu系统的分区进行修改了，修改完点击确认等待扩容操作完成即可。

\subsubsection{grub美化*}

也许你对那个系统启动时进入ubuntu的黑框框觉得厌烦了，而且每次启动系统都得手动点一下对应选项，或是觉得每次启动ubuntu都需要BIOS特意去设置一下真是太繁琐了，其实这只是因为你默认的这个grub没有美化而已，我们下面来解决这个问题。

在这个网页中

\url{https://www.gnome-look.org/browse?cat=109&ord=latest}

我们可以找到很多grub的主题。挑一个你喜欢的。笔者自己使用的是

\url{https://www.gnome-look.org/p/1307852}

这款主题。具体的安装教程在这个主题的git仓库中

\url{https://github.com/vinceliuice/grub2-themes}

如果你选择其他主题的话，教程位置可能变化，你需要自己找找。

你可以下载这个仓库到你的ubuntu系统中（github的很多功能都和git有关，但是在介绍git之前，你可以通过点击网页中的code按钮点击download zip下载）。然后按照这个主题中的README.md文件的教程安装。

\begin{tbash}
sudo ./install.sh -t tela -s 2k
\end{tbash}

完成了这一步后，如果你用的是笔者的这个主题，启动时就可以看到这样的界面了。而且10s没有操作可以自动进入ubuntu系统。

\begin{figure}[H]
    \centering
    \includegraphics[width=0.7\textwidth]{grub.png}
    \caption{Tera主题} % 图片标题
\end{figure}

不过也许你还需要在没有操作的情况下进入Windows。那么我们需要小小的配置一下grub的配置文件。我们需要修改 \verb|/etc/default/grub| 这个文件，找到\verb|GRUB_DEFAULT=0|这一行，看一下你的windows系统在启动时在哪一行（一般是第3行），我们将这个0修改为行数减一（一般是2）即可。

\subsubsection{桌面美化*}

grub 好看了，桌面也不能输。Ubuntu 22.04 默认的 GNOME 桌面虽然朴素，但换个主题、装几个插件之后，颜值完全可以反超 Windows。本节为选修内容。

\textbf{主题与图标}

GNOME 的主题和图标可以在 \url{https://www.gnome-look.org/} 上挑选：左侧分类里 GTK3/GTK4 Themes 是窗口主题，Full Icon Themes 是图标包。下载得到的一般是压缩包，解压到对应目录即可被系统识别：

\begin{example}
把下载好的主题和图标解压到用户主题目录（目录不存在就先创建）：
\begin{tbash}
mkdir -p ~/.themes ~/.icons
tar -xf 主题包.tar.gz -C ~/.themes
tar -xf 图标包.tar.gz -C ~/.icons
\end{tbash}
\end{example}

装好后需要 GNOME Tweaks（GNOME 优化）来切换主题和图标，顺便装上后面要用的插件管理器：

\begin{example}
安装 GNOME Tweaks 与 Extension Manager（插件管理器）：
\begin{tbash}
sudo apt install gnome-tweaks gnome-shell-extension-manager
\end{tbash}
\end{example}

打开 Tweaks，在"外观"一栏即可选择刚装好的主题和图标。Extension Manager 则是本节的主角：它能直接在桌面上浏览、安装、开关各种 GNOME 插件，不用再去网页上折腾。

\begin{note}
