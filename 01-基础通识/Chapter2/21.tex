\subsubsection{类的基本概念}

类是\textbf{面向对象}（OO，Object-Oriented）最基本的概念，也是C++区别于C语言的重要特征。
面向对象编程的基本思想是抽象出对象，将对象作为程序的基本单元，通过消息传递来进行通信和协作。
对象是类的实例，具有状态和行为：状态存储在对象的数据成员中，行为由对象的成员函数实现。
面向对象编程的优点是代码的可重用性、可扩展性和可维护性都得到了提高。

在C++中，类是一种抽象数据类型，它定义了对象的行为和状态，并提供了对这些数据的访问接口。
类可以包含数据成员、成员函数、构造函数、析构函数等，这些成员构成了类的接口。
类可以派生出新的类，从而实现代码的重用和扩展。

\begin{example}
类的基本结构（骨架代码，先混个眼熟）：
\begin{tcode}
class ClassName{        //类名
    public:             //修饰限定符public
        ClassName();    //构造函数
        ~ClassName();   //析构函数
        void memberFunction();  //成员函数
    private:                    //修饰限定符private
        int dataMember;         //数据成员
        void privateFunction(); //私有成员函数
};  //注意：类定义结束的花括号后面有一个分号
\end{tcode}
\end{example}

\begin{enumerate}
    \item \textbf{构造函数和析构函数}：负责对象的初始化和释放，其特点是函数名与类名相同，没有返回值。
    \item \textbf{成员函数}：实现类的行为，它们实现了类的功能。
    \item \textbf{数据成员}：存储类的数据信息。
\end{enumerate}

\begin{center}
    \begin{tabular}{cc}
        \toprule[1.5pt]
        修饰限定符 & 作用 \\
        \midrule[1pt]
        private & 只能被类的成员函数使用或调用 \\
        public & 可以被类外的其他函数或派生类中函数调用 \\
        protected & 只能被类的成员函数和派生类使用或调用 \\
        \bottomrule[1.5pt]
    \end{tabular}
\end{center}

顺带一提，C++是一门\textbf{多范式}语言：既可以像C语言那样面向过程（数据和函数分离，通过函数调用组织逻辑），
也可以面向对象，还可以用模板进行泛型编程。本章后面的小节会逐一见到它们。

\begin{note}
\texttt{struct} 和 \texttt{class} 在 C++ 中几乎完全等价，\textbf{唯一的区别是默认权限}：
\texttt{struct} 的成员默认 \texttt{public}、默认公有继承；\texttt{class} 的成员默认 \texttt{private}、默认私有继承。
除此之外，\texttt{struct} 一样可以有构造函数、成员函数、继承和多态。
习惯上 \texttt{struct} 用于纯数据打包（如坐标点），\texttt{class} 用于需要封装的对象。
\end{note}

\textbf{番外：指名初始化（Designated Initializers）。}
对于没有自定义构造函数的简单结构体（聚合类型，Aggregate Type），C++20 允许在初始化时指名道姓地给成员赋值，
而不必按照成员的声明顺序来写：

\begin{example}
指名初始化：
\begin{tcode}
//类型名 对象名{.成员名1 = 初始值1, .成员名2 = 初始值2, ...};
struct Foo {int a, b};
Foo foo = {.b = 3, .a = 1};
\end{tcode}
\end{example}

\subsubsection{静态和友元}

\textbf{静态成员}（static member）属于整个类，而不是某个具体对象。
无论创建多少个对象，静态成员在内存中只有一份，被类的所有对象共享，因此可以实现一些全局变量的功能。
静态成员在类内用 $static$ 关键字\textbf{声明}，但必须在类外\textbf{定义}（分配内存），且只定义一次。
静态成员的生命周期和整个程序相同，程序结束时才释放。

\textbf{友元函数}（friend function）：有时我们希望某个函数可以访问类的私有成员，但又不希望它成为类的成员函数。
这时可以在类的声明中用 $friend$ 关键字把它声明为友元函数。友元函数不是类的成员，实现时不加类的作用域，
但可以访问类的私有成员。

\begin{example}
静态成员与友元函数的用法：
\begin{tcode}
#include <iostream>

class ClassName {
    public:
        ClassName() = default;
        ~ClassName() = default;

        static void memberFunction();           //静态成员函数
        static int dataMember;                  //静态数据成员，类内声明
        friend void FriendFunction(ClassName& obj); //友元函数声明
    private:
        int secret = 42;                        //私有数据成员
};

int ClassName::dataMember = 10; //静态数据成员在类外定义，且只定义一次

void FriendFunction(ClassName& obj){ //友元函数实现时，不可以添加类的作用域
    std::cout << "友元函数访问私有成员：" << obj.secret << std::endl;
}

int main(int argc, char *argv[]) {
    ClassName obj1, obj2;
    std::cout << obj1.dataMember << std::endl;  //输出10
    std::cout << obj2.dataMember << std::endl;  //还是10，两个对象共享同一份
    FriendFunction(obj1);
    return 0;
}
\end{tcode}
\end{example}

\begin{note}
友元函数不属于类，它破坏了类的封装性，因此不建议使用！把私有成员的访问权随意送出去，
相当于把家门钥匙配了一把给邻居——邻居是不是好人另说，钥匙给多了总会出事。
\end{note}

\subsubsection{函数重载}
\textbf{函数重载（overload）}是指在同一个作用域中，存在多个同名函数，但它们的参数个数或参数类型不同。
函数重载的作用是为了使程序更加灵活，提高代码的可读性和可维护性。

在C++中，函数重载的规则是：
\begin{enumerate}
    \item 函数名相同；
    \item 参数个数不同，或参数类型不同。
\end{enumerate}

\begin{example}
同名不同参的 \texttt{CalSum}：
\begin{tcode}
#include <iostream>

class ClassName {
public:
    ClassName() = default;
    ~ClassName() = default;

    int CalSum(int a,int b){
        return a+b;
    }

    double CalSum(double a,double b){
        return a+b;
    }
};

int main(int argc, char *argv[]) {
    ClassName obj;
    std::cout << obj.CalSum(1,2) << std::endl;
    std::cout << obj.CalSum(1.5,2.5) << std::endl;
    return 0;
}
\end{tcode}
\end{example}

在上例中，CalSum函数的两个版本参数类型不同，编译器会根据调用时传入的实参，自动选择最匹配的函数版本。

\begin{note}
\textbf{仅返回值不同不能构成重载}。调用函数时编译器看不到你打算把结果赋给什么类型，
如果只靠返回值区分，编译器将无法确定该调用哪一个版本，直接报二义性错误。
\end{note}

\subsubsection{构造函数}

\textbf{构造函数的类型：}

\begin{enumerate}
    \item 默认构造：默认构造函数是指没有参数的构造函数，它会创建一个对象，并对其进行初始化。
    \item 含参构造：含参构造函数是指有参数的构造函数，可以根据参数的值对对象进行初始化。
    \item 拷贝构造：拷贝构造函数是指将一个对象拷贝到另一个对象时，会调用拷贝构造函数。
\end{enumerate}

\begin{example}
三种构造函数的调用时机，注意每一次的输出：
\begin{tcode}
#include<iostream>
#include<string>
class ClassName {
public:
    ClassName():member(1) //初始化列表
    {std::cout << "你调用了默认构造函数" << std::endl;}
    ClassName(std::string& str)
    {std::cout << "你调用了含参构造函数，参数是" << str << std::endl;member=2;}
    ClassName(ClassName &obj) //这里必须是引用传参，思考一下为什么
    {std::cout << "你调用了拷贝构造函数" << std::endl;
    this->member = obj.member;}
    ~ClassName() = default;

    int member;
};

int main(int argc, char *argv[]) {
    ClassName obj1;
    std::string str = "Hello World";
    ClassName obj2(str);
    obj1.member = 10;
    ClassName obj3(obj1);

    std::cout << "obj1:" << obj1.member << std::endl;
    std::cout << "obj2:" << obj2.member << std::endl;
    std::cout << "obj3:" << obj3.member << std::endl;

    return 0;
}
\end{tcode}
\end{example}

有一些tips可以快速设置构造函数：
\begin{tcode}
ClassName() = default;              //默认构造函数,使用默认的方式
ClassName(ClassName& obj) = delete; //禁止拷贝构造，单例实现对象
\end{tcode}

\subsubsection{运算符重载与 this 指针}

在C++中，类提供了一个接口，可以将运算符进行重载，从而实现对类更加灵活的操作。
运算符重载的语法如下：

\begin{tcode}
[返回值] operator [操作符] ([参数列表]) {
    //操作符的实现
}
\end{tcode}

\begin{example}
重载加法运算符与流插入运算符：
\begin{tcode}
#include <iostream>

class ClassName {
public:
    ClassName():a(1),b(2) {}

    ClassName& operator+(ClassName& obj){//重载加法运算符
        this->b += obj.b;   //this指针，指向自己
        this->a += obj.a;
        std::cout << "这里执行过了" << std::endl;
        return *this;   //*this表示当前对象的引用
    }

    //重载流插入运算符，思考一下为什么是这样写？
    friend std::ostream& operator<<(std::ostream& out, ClassName& obj);

    int a;
    int b;
};

std::ostream& operator<<(std::ostream& out, ClassName& obj){
    out << "a:" << obj.a << " b:" << obj.b << std::endl;
    return out;
}

int main(int argc, char *argv[]) {
    ClassName obj1;
    ClassName res = obj1 + obj1;
    std::cout << res;
    return 0;
}
\end{tcode}
\end{example}

\textbf{$this$指针}是一个隐指针，指向这个类本身。
在类的成员函数中，$this$指针可以用来访问类的成员变量和成员函数。
一般情况下，$this$指针可以不写，编译器会自动生成。但是有些情况，出于项目代码可读性的目的，会写显式的$this$指针。

\subsubsection{类的继承}
类的继承是面向对象编程的重要特征之一，它允许创建新的类，从而继承基类的成员，并添加新的成员。

\begin{figure}[H]
    \centering
    \includegraphics[width=0.7\textwidth]{A111.png}
    \caption{类的继承} % 图片标题
    \label{fig:A111} % 图片标签，用于引用
\end{figure}

如图\ref{fig:A111}所示，派生类从基类中继承了数据成员和成员函数，并可以添加新的成员。
派生类可以重写基类中的成员虚函数，从而实现新的功能。
派生类可以重载基类中的运算符，从而实现新的运算。

基类成员的访问限定符，决定了派生类和类外部能否访问它们。
这张表和"类的基本概念"中的是同一张，这里从继承的视角再看一次——重点关注"派生类"这一行：

\begin{center}
    \begin{tabular}{cccc}
        \toprule[1.5pt]
        访问位置 & public 成员 & private 成员 & protected 成员 \\
        \midrule[1pt]
        同一个类 & yes & yes & yes \\
        派生类 & yes & no & yes \\
        类外部 & yes & no & no \\
        \bottomrule[1.5pt]
    \end{tabular}
\end{center}

继承可以用下面的写法实现：

\begin{example}
抽象基类与两个派生类：
\begin{tcode}
#include <iostream>

class Shape {//这个基类只含有纯虚函数，又叫做抽象类
public:
    Shape() = delete;
    Shape(double A):Area(A)
    {std::cout << "基类的构造函数已经被调用" << std::endl;}
    virtual double calArea() = 0; //这里是纯虚函数，也可以使用普通函数
    double Area;
};

class Rectangle
        : public Shape{
public:
    Rectangle() = delete;
    Rectangle(double a,double b):Shape(a*b),a(a),b(b)
    {std::cout << "Rectangle类的构造函数已经被调用，面积为" << Area << std::endl;}
    double a;
    double b;
    double calArea() override{  //重写基类的函数
        return a*b;
    }

};

class Circle
        : public Shape{
public:
    Circle() = delete;
    explicit Circle(double r):Shape(3.14*r*r),r(r)
    {std::cout << "Circle类的构造函数已经被调用，面积：" << Area << std::endl;}
    double r;
    double calArea() override{
        return 3.14*r*r;
    }

};

int main(int argc, char *argv[]) {
    Circle circle(1.0);
    Rectangle rect(1.0,2.0);
    return 0;
}
\end{tcode}
\end{example}

\begin{note}
继承方式有三种：\texttt{public}、\texttt{protected}、\texttt{private}（不写时默认 \texttt{private}），
它决定了基类成员在派生类中的访问权限上限。工程中绝大多数情况都用 \texttt{public} 继承，
另外两种仅作了解。含纯虚函数的抽象类不能直接实例化，只能作为基类使用。

另外注意初始化列表的写法：\textbf{基类构造函数写在成员之前}，成员之间按\textbf{声明顺序}初始化，
与列表里的书写顺序无关。写错顺序编译器会发出 \texttt{-Wreorder} 警告，如果成员之间存在初始化依赖，还会得到未定义的值。
\end{note}

\begin{conclusion}
重载（overload）与重写（override）仅一字之差，但完全是两回事：

\begin{itemize}
\item 重载 overload：同一作用域内的同名函数，参数列表不同，编译期由编译器选择版本，与继承无关；
\item 重写 override：派生类重新实现基类的 \texttt{virtual} 函数，函数签名必须相同，运行期根据对象实际类型决定调用哪个版本（多态），建议显式标注 \texttt{override} 让编译器帮忙检查；
\item 纯虚函数 \texttt{= 0}：基类只给接口不给实现，含有纯虚函数的类是抽象类，不能实例化。
\end{itemize}
\end{conclusion}

 \subsubsection{模版}
在开发过程中，我们可能会遇到这样的场景：我们有一个函数或者类，但是它只适用于特定的数据类型，
比如$int$或者$double$。为了让这两种类型都可以调用函数，
就得把代码复制一遍，但这样做就造成了代码冗余，不利于维护。这时候就需要用到模版（$template$）。

模版是C++中一个重要的特性，它允许我们定义一个类或函数，使其可以接受不同的数据类型或者不同的参数。
模版的定义和使用都比较复杂，这里只介绍最基本的用法。
\textbf{函数模版}用 $template$ 加尖括号声明一个类型参数（习惯命名为 $T$），之后 $T$ 就可以像普通类型一样使用。语法如下：
\begin{tcode}
template<class T>
T function(T a){
    return a;
}
\end{tcode}

这里的$class \quad T$表示一种数据类型，可以是任意类型。
在函数的定义中，$T$可以作为函数的参数，也可以作为函数的局部变量。在使用函数模板时，需要首先进行函数的实例化。

\begin{example}
函数模版的实例化与调用：
\begin{tcode}
#include <iostream>
#include <functional>

template<class T>
T function(T a){
    return a;
}

int main() {
    //调用的时候实际上分为两步，实例化和调用
    function<int>(10);
    function<double>(20.0);
    //在编译器可以推导出类型的时候可以不加<>
    auto a = function(1.0);
    //在无法推导的时候，要先进行实例化
    std::function<int(int)> ptr = function<int>;
    return 0;
}
\end{tcode}
\end{example}

模版的优点：
\begin{enumerate}
    \item 代码重用性高：可以定义一个通用的函数，然后根据需要实例化不同的类型，实现代码的重用。
    \item 类型安全：模版可以保证类型安全，避免类型错误。
    \item 效率高：模版可以提高效率，因为编译器可以对代码进行优化。
\end{enumerate}

\textbf{类模版}：
类模板的语法和函数模板类似，只不过在类名而不是函数名前面加上关键字$template$。
在普通类中也可以添加成员函数模版，只需要在函数名前面加上关键字$template$即可。

\begin{example}
类模版的基本写法：
\begin{tcode}
#include <iostream>

template<class T1,class T2>
class A{
public:
    A() = default;
    ~A() = default;
    T1 val;
    T2 id;
    void print(){
        std::cout << val << " " << id << std::endl;
    }
};

int main() {
    A<int, double> a; //实例化时填具体类型
    a.val = 1;
    a.id = 2.5;
    a.print();
    return 0;
}
\end{tcode}
\end{example}

模板参数除了类型，还可以是\textbf{编译期常量}（非类型模板参数），常用于指定数组长度这类编译期就要确定的值：

\begin{example}
非类型模板参数：
\begin{tcode}
template<int N>
int getConst(){
    return N;
}

int main() {
    int v = getConst<42>(); //v = 42
    return 0;
}
\end{tcode}
\end{example}

在$template$后面，可以定义多个类型参数，用逗号分隔。需要注意的是，类中的函数模版需要在头文件中实现，
也就是说，模版的声明和实现不可以分离，否则会出现很多问题。
对于类模板也可以实现继承和多态，与普通类相同，这里不再展开，感兴趣的同学可以自行探索。

\textbf{模板的实例化}：
模板的实例化指的是将模板定义和具体的模板参数绑定在一起，生成一个具体的类或函数。
写 $A<int, double>$ 时，编译器会根据尖括号里的参数生成对应的版本。模板参数可以填两类东西：

\begin{enumerate}
    \item 具体类型：如$int$、$double$等基本类型，$struct$、$class$、$union$等复合类型，以及指针和引用类型；
    \item 编译期可以确定的常量：字面常量、宏、$constexpr$，对应上面的非类型模板参数。
\end{enumerate}

平时我们写的 $function<int>(10)$ 其实叫\textbf{隐式实例化}——用到时才生成；
也可以在代码里写 \texttt{template class A<int, double>;} 主动要求编译器立刻生成，这叫\textbf{显式实例化}，
常用于模板分离编译的场景，初学阶段了解即可。

除此之外，还有一种变参模版，它可以接受任意数量的类型参数，但是在实例化时，必须指定具体的类型。
这种情况比较复杂，这里不再展开。
