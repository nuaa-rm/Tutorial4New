\section{本章验收}
\begin{enumerate}
    \item 定义表示平面点的结构体或类，重载输出运算符，打印若干角点坐标。
    \item 使用 lambda 作为比较器，对自定义结构体数组排序。
    \item 说明拷贝构造函数参数必须为引用的原因，以及按值传递将导致的问题。
    \item 使用 \texttt{std::vector} 等容器管理一组对象，并说明优先使用智能指针管理堆内存的原因。
    \item 实现线程安全队列，或完成 \texttt{参考文献/multithread.pdf} 中 Phase~1，并用测试验证。
\end{enumerate}
