\subsection*{技术组概览}
技术组负责机器人运动、控制与感知相关的研发与集成，通常划分为以下组别。

\begin{itemize}
    \item \textbf{机械组}：完成结构设计与实现，保证运动能力与结构可靠性；常用 SolidWorks 等工具，并在轻量化与强度之间权衡。
    \item \textbf{电控组}：负责嵌入式运动控制、通信与电路，硬件设计与焊接亦常归入该组；常用 Keil、STM32Cube 与 EDA 工具。
    \item \textbf{视觉组}：为目标识别、环境感知、定位与追踪提供算法与软件；常用 C++、OpenCV、PyTorch、ROS2、Navigation2 与 Behavior Tree。
\end{itemize}

各组需密切协作：机械提供承载平台，电控执行控制指令，视觉提供环境感知能力。本教材面向视觉组新生。

\subsection*{视觉组职责}
视觉组使机器人具备赛场感知能力，实时识别敌方目标与关键物体，并结合多传感器完成定位、追踪与决策支持。组内常见方向如下。

\begin{itemize}
    \item \textbf{自瞄}：基于相机与图像处理或深度学习识别装甲，估计并预测目标运动，将瞄准信息提交控制系统。
    \item \textbf{导航}：融合激光雷达、IMU 等传感器，结合 SLAM 与路径规划，实现自主行进与任务执行，常用 ROS2 与 Nav2。
    \item \textbf{雷达}：利用高处视角与算力识别全场目标位置等信息，并向队友共享。
\end{itemize}

\subsection*{工作内容}
\begin{enumerate}
    \item \textbf{目标识别与跟踪}：采用传统视觉方法与深度学习检测；跟踪环节常用滤波等方法维持目标连续性。
    \item \textbf{图像处理}：完成采集、去噪、增强与特征提取，为识别与标定提供可靠输入。
    \item \textbf{深度学习}：利用卷积神经网络等完成检测、分类与分割，提升复杂背景下的识别能力。
    \item \textbf{定位与导航}：视觉、激光等传感器参与定位与建图，支撑自主移动。
    \item \textbf{传感器选型与调试}：完成相机、深度相机、激光雷达等设备的选型与联调，保证成像质量与接口稳定。
\end{enumerate}

\subsection*{能力要求}
\begin{itemize}
    \item \textbf{C++ 基础}：类、现代语法、容器、智能指针与多线程。上述内容构成本卷教学重点。
    \item \textbf{图像与学习}：图像处理、OpenCV 与深度学习基础。相关内容见卷二。
    \item \textbf{系统与工程}：ROS2、导航、估计与控制等专项见卷二；赛场链路与工程准则见卷三。
\end{itemize}

\subsection*{主要挑战}
复杂光照与背景、实时性与算力约束、多传感器融合，以及软硬件协同调试，将贯穿整个赛季。通识阶段应先掌握工具与语言，再进入专项训练。
