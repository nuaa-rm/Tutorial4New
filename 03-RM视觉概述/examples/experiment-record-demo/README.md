# 保留失败和回滚的单变量实验记录

依赖Python3.10+标准库，前置是卷三雷达站章的radar-fusion-demo。复用其完整消息/选源代码，本项目不再复制实现；会读取同一输入，只改radio限龄，再按**预先固定的100ms任务判据**判断结果。

从本目录执行，record路径是本次输出文件，会覆盖同名旧文件，因此基线、试验和回滚用不同名字：

```bash
python3 run.py --radio-limit 100 --record out/baseline.json
python3 run.py --radio-limit 200 --record out/trial.json
python3 run.py --radio-limit 100 --record out/rollback.json
```

基线选择50ms的视觉，passed=true；放宽限龄后选择150ms无线电，passed=false；回滚后再次选择视觉50ms，passed=true。输入文件、源代码散列与固定条件应相同，变化的是radio_limit_ms以及由此产生的观测与结论。限龄放宽确实让无线电被选中，但违反原先100ms任务条件；不能为了让试验“成功”再把任务判据改成200。

这是同一人工消息的软件实验，未证明硬件、实时调度、现场误差、无线电权限或实车性能。项目记录假设、单变量、固定条件、源版本、原始选源检查、判据和边界。不要把软件通过写成实机通过。source_sha256覆盖未提交文件的具体内容；input_sha256帮助另一位同学确认同一输入，不含凭空编写的Git提交号。

读三个JSON，把失败原因和回滚复核写进自己的记录；再请另一位同学按同样命令重跑并签明实际复核时间与结论。没有复核人就标为待复核，不填写虚构姓名。接口未变化，固定的目标身份/单位/时钟/有效性前提沿用雷达章。若换了输入、程序或判据，应另开实验，不混进原单变量结论。
