\section{原则：原理在卷二，本章是 checklist}

曝光三角、卷帘快门、噪声等原理见卷二「相机与成像」。本章只列赛场上最常踩坑的实践要点。

\section{卷帘 vs 全局}

\begin{itemize}
    \item \textbf{卷帘快门}：高速相对运动时易倾斜、撕裂，影响角点与检测稳定性；
    \item \textbf{全局快门}：运动场景更稳，成本与选型受限。
\end{itemize}
自瞄对抗、云台快速扫场时，快门类型与曝光时间必须一起评估：曝光过长同样拖影。

\section{分辨率、帧率与「商家高清」}

\begin{itemize}
    \item 宣传「高清」不等于赛场可用分辨率；
    \item 帧率常与分辨率绑定：高帧可能对应较低分辨率；
    \item 流水线延迟 = 曝光 + 传输 + 推理 + 解算 + 控制，只拉高分辨率可能整体更慢。
\end{itemize}
选型时写清：目标分辨率、最低可接受帧率、接口（USB3/GigE）、黑白/彩色、触发方式。

\section{曝光 / 增益 / 触发 checklist}

上机前逐项确认：
\begin{enumerate}
    \item 灯条不过曝成一片、暗部仍可见结构；
    \item 增益过高引入的噪声是否拖垮阈值/网络；
    \item 是否固定曝光（自动曝光在对抗光照下常致命）；
    \item 硬件触发 / 同步是否与电控时间戳约定一致；
    \item 镜头焦距与工作距离是否匹配装甲成像尺寸；
    \item 内参与畸变是否在本机标定，配置是否写对序列号。
\end{enumerate}

雷达俯视与车载自瞄的工作距离、FOV 不同，\textbf{禁止}共用一套未经验证的曝光参数。

\section{工业相机与 SDK*}

赛场常用厂家 SDK（如海康）按序列号打开，而不是笼统 \texttt{VideoCapture(0)}。
驱动、权限、USB 带宽不足时会丢帧——先查系统层再查算法。

\section{验收}

能在调车现场按 checklist 检查一台相机，并说明卷帘+长曝光组合的主要风险。
