\section{任务定义}

自瞄要在对抗中完成：
\begin{center}
检测装甲 $\rightarrow$ 跟踪与预测 $\rightarrow$ 云台到达可击打位姿 $\rightarrow$ 开火窗口
\end{center}

成功不只看「偶尔打中」，而看：命中率、稳定性、抗小陀螺、端到端延迟、暗光/曝晒下的可复现性。

\section{目标检测（概述）}

检测输出通常是装甲板在图像中的位置（常落实到灯条\textbf{角点}），再进入空间解算。

\begin{itemize}
    \item \textbf{传统路径}：颜色/亮度分割、轮廓与几何约束、数字识别；实时性好，依赖曝光与阈值。
    \item \textbf{深度路径}：检测网络泛化更好，需权衡输入分辨率、算力与 TensorRT 部署。
\end{itemize}

空间位置解算本质是投影的反问题，工程上归结为 \textbf{PnP}：已知装甲三维模型点与图像点，求相机（或云台）相对位姿。
有噪声时，鲁棒性往往比「理想四点精密解」更关键。细节回卷二 OpenCV、深度学习与 BA/PnP 章。

\section{目标跟踪与预测（概述）}

单帧检测会跳变、丢帧；跟踪把多帧状态连贯起来，并为开火提供\textbf{预测}。

由于小陀螺等，单块装甲板运动极复杂，常见做法是对\textbf{整车}建模（位置、速度、姿态相关量），再映射到当前可见装甲。
\textbf{Kalman / EKF} 等在链路中承担「带噪声的状态估计」：过程噪声与观测噪声定得不好，会出现滞后或抖动。细节回卷二滤波章。

主要噪声来源（口述链路时请标出）：
\begin{itemize}
    \item 检测：误检、漏检、角点抖动；
    \item 解算：标定误差、运动模糊、深度接近退化；
    \item 估计：模型不匹配、参数 $Q/R$ 不当；
    \item 控制：云台延迟、饱和、机械间隙。
\end{itemize}

\section{云台控制（概述）}

有了「期望射击角」仍不够：云台有惯量、延迟与限幅，弹丸飞行期间目标还在动。

\begin{itemize}
    \item \textbf{弹道}：距离、弹速、下坠等用拟合或表驱动补偿；
    \item \textbf{云台}：从指令到实际转角是动态系统；简单「看到就拉」在高速目标上易失跟。
\end{itemize}

\textbf{MPC} 一类方法在模型与约束下规划短时域控制，滚动执行，用于提升可响应范围内的跟踪质量。细节回卷二 MPC 章。

\section{最小二乘统一视角（导读）}

BA、Kalman、MPC 都可看成：定义误差指标，在约束下优化使之最小。
\begin{itemize}
    \item BA：重投影误差；
    \item Kalman：估计误差方差意义下的最优融合；
    \item MPC：预测轨迹与控制能量的折中。
\end{itemize}
本卷不展开公式；学有余力进入卷二 G/F/H，调车时则优先用已验证实现。
