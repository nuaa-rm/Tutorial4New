# 视觉组教材封面

三卷共用「青色 + 深蓝灰 + 白色」设计。每份 PDF 含两页：封面、内标题页（学习导览）。

根目录原有 `cover.pdf` 和队徽素材保留，新的封面不依赖旧封面图片。
顶部标识区组合新版队徽、`NUAA` 与「长空御风」，并保留完整校名。
标识、封面主标题、卷册主题与大卷号使用项目内的 `../../fonts/站酷高端黑.ttf`，直接通过 fontspec/xeCJK 加载，不要求系统安装该字体。
内页主题与大卷号沿用这款字体，说明文字继续使用原有易读字体；字体设置不影响正文。
学习导览页采用工程制图风格：切角卷标、带网格与定位角标的卷号、页边刻度、三阶段连线及切角内容面板。青色主线搭配小面积珊瑚橙标记；装饰由 TikZ 绘制，导览文字可编辑，三卷自动适配。
封面两行主标题使用 54 pt，卷册主题使用 27 pt，突出站酷高端黑的几何结构。
封面与导览页共用细线网格、定位角标、页边刻度和珊瑚橙点缀；封面的大卷号带淡色网格，插画只加两组外侧角标，关键词放入浅色切角条，保留原有大标题和镜头插画的留白。

## 新版队徽

输入是 `../textures/team_icon.png`，即用户提供的黑色透明底新版几何队徽。
SVG 为真实路径，未嵌入 PNG；20 个分块按 `wing`、`crest`、`head`、`tail` 命名，方便定位与修改。
翼部与头部使用青绿、深蓝绿（`#55CAD0`、`#1FBABE`、`#127D91`、`#225769`）；眉羽使用珊瑚色 `#D75B4C`，尾翼从陶橙 `#CB5C49`、珊瑚橙 `#E97953` 过渡到暖金 `#F1AF64`。冷暖对比让标志在青色封面中更突出。
文件沿用 `team-emblem-cyan` 名称以保持引用一致；单色版仍为深蓝灰 `#16343E`。
透明背景与原始构图保留；原版彩色队徽及黑白输入都没有被改写。

`vectorize-emblem.py` 从透明通道提取边界、简化折线，并从同一组路径同时导出 SVG、PDF 与 PNG。需要 Python、NumPy、Pillow 和 ReportLab。
`team-emblem-trace.json` 保存各块坐标、颜色和轮廓核对结果。手工改动 SVG 后，需同步更新 LaTeX 使用的 PDF。

## 在教材中复用

共用排版在 `../../templates/cover.tex`，由 `preamble.tex` 自动载入。
每卷 `main.tex` 在 `\maketitle` 前设置：

```latex
\TextbookVolume{1} % 卷一用 1，卷二用 2，卷三用 3
```

`\maketitle` 输出两页，卷号、主题、内容关键词和学习导览随卷号切换；编写者、版本和页底说明读取各卷已有的 `\author`、`\version`、`\extrainfo`。
卷三封面用「RM 视觉概述」短标题，与项目卷名一致。
文字由 LaTeX 排版，可选择、检索和修改；插画只承担装饰作用，不作为光学原理示意图使用。

修改配色、位置和每卷导览文字，请编辑 `templates/cover.tex`。
共用颜色为 `#1FBABE`（与正文 cyan 一致）、`#16343E`、`#536E76` 和 `#E8F7F7`。
封面使用整页坐标，并局部设置字号和行距，不改正文页边距、章节层级和习题编号。

## 重新导出

在本目录执行：

```powershell
.\build.ps1
```

需要 XeLaTeX；如能找到 `pdftoppm`，还会刷新每页 PNG。
`preview.tex` 只编译封面，不需要编译整本教材；其中版本与页底说明应与各卷主文件同步。
TikZ 整页定位需要编译两遍；首遍的图片位置不能作为最终效果。
正常编译各卷时同样运行两遍 `xelatex main.tex`。

## 插画来源

使用内置 `image_gen` 生成，未使用 API/CLI 备选流程。生成提示词见 `image-prompt.txt`。
原始生成图复制到本目录，项目不会引用用户目录中的临时资源。
如需改变插画，新增文件并修改 `\TextbookCoverArt` 即可。
